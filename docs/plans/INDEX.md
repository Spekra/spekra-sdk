# Plans Index

This index provides a quick map of implementation plans kept under `docs/plans`.

Status policy:

- `Active`: currently being executed or pending final validation
- `Completed`: implemented and retained for historical context
- plan files themselves are historical records; use this index to track current
  status instead of rewriting older plan docs

## Update Process

1. Create a new dated plan file for each substantial work item; do not rewrite
   older plan files.
2. Add new plans to `Active` when work starts.
3. Move only the index entry to `Completed` when work lands and validation is
   done.
4. Keep this file sorted newest-first inside each section.
